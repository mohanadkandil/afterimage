# Third-party components

- **nlohmann/json** — vendored single header, MIT; copyright and license included in `vendor/nlohmann/json.hpp`.
- **SQLite / FTS5** — system library, public domain. No SQLite source is vendored.
- **Apple AppKit, WebKit, ScreenCaptureKit, Vision and ImageIO** — system frameworks provided by macOS, subject to Apple's terms.
- **Clang / CMake / Python** — development tools, not bundled runtime services.

Coast is product inspiration. No Coast implementation, private archive, images or trademarks are bundled. The Litt brand mark and test document are generated by this repository's asset script.
